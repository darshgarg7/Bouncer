# Public roadmap

Roadmap items are bounded evidence milestones, not promises of production status.

## v0.1 — Reproducible control-plane prototype

- [x] Deterministic Go policy and Python parity oracle.
- [x] Virtual, remote, and rooted Linux execution boundaries.
- [x] Lifecycle-complete event verification and external hash anchors.
- [x] Source-bound synthetic studies and honest hosted connectivity pilot.
- [x] Credential-free live demo and publication audit.
- [x] Shadow-gated learned-routing substrate.
- [x] Static anomaly scoring with explicit shadow and active circuit-breaker modes.
- [ ] Publish signed release artifacts after GitHub infrastructure is configured.

## v0.2 — External evaluation

- [ ] Pre-register one AgentDojo-style security evaluation.
- [ ] Integrate one realistic task benchmark with equal-permission baselines.
- [ ] Run multiple model families and seeds with uncertainty intervals.
- [ ] Publish negative results and a fully reproducible evaluation bundle.
- [ ] Qualify an active anomaly artifact on labeled held-out benign and adverse
  windows; the checked-in bootstrap remains shadow-only.
- [ ] Add a frozen-price provider-cost ledger when paid comparative studies
  begin; keep proposal spend separate from metered execution cost.

## v0.3 — Execution qualification

- [ ] Add explicit read-deny rules.
- [ ] Complete adversarial filesystem and gVisor containment campaigns.
- [ ] Add workload identity, request limits, egress validation, and recovery drills.
- [ ] Generate SBOMs, signatures, and build provenance in release CI.

## Good first issue candidates

- Add table-driven tests for invalid CLI flag combinations.
- Add an event-verifier fuzz corpus for duplicate lifecycle records.
- Add a compatibility fixture for the v0.1 run manifest.
- Add a sample Grafana dashboard for existing Prometheus metrics.
- Improve one benchmark report renderer without changing its JSON source.

Open an issue before implementing a roadmap item that changes a trust boundary.
