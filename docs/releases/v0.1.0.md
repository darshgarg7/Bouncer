# Bouncer v0.1.0 release notes

> Draft: publish only after hosted CI and release artifacts are verified.

## Highlights

- Deterministic authorization for model-proposed actions.
- Virtual, authenticated remote, and rooted Linux execution paths.
- Complete lifecycle verification with externally anchorable event hashes.
- Reproducible controlled studies and an honestly scoped 2/3 hosted pilot.
- Optional learned routing behind explicit shadow and active promotion modes.
- One-command, credential-free live demonstration.

## Verification

The final release notes must include the exact commit, `make release-check`
result, Linux/macOS GitHub Actions URLs, binary checksums, image digests, SBOM
locations, and signature/provenance identifiers.

## Known limitations

This is a research prototype. The hosted pilot is connectivity evidence, the
synthetic studies are authored fixtures, the Linux broker is not independently
qualified, and learned routing has not demonstrated real-task improvement.
