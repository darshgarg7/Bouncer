# ADR 0005: Causal and off-policy analysis stays offline

**Status:** Accepted
**Date:** 2026-07-26

## Context

Production logs are generated by a selection policy, trajectories are sequential, and unsupported actions have zero observational probability. Causal terminology without supported interventions would overstate the evidence.

## Decision

Randomized paired system experiments are the primary evidence path. Optional off-policy evaluation lives in a separate laboratory and requires exact propensities, supported reusable treatments, overlap and effective-sample-size diagnostics, known-ground-truth validation, and estimator agreement.

The PC algorithm is removed from the main implementation story. Causal discovery requires its own research question and validation before inclusion.

## Consequences

- No causal library is part of the authorization hot path.
- Exploration is limited to policy-passing actions in reversible environments.
- Offline results remain advisory and cannot weaken deterministic policy.
