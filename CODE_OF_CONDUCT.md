# Code of conduct

## Our standard

Contributors must communicate respectfully, critique ideas and evidence rather
than people, disclose relevant conflicts, and avoid harassment, discrimination,
threats, doxxing, or sexualized conduct. Security discussions must not expose
credentials, private prompts, or unpatched vulnerability details.

## Enforcement

Project maintainers may edit or remove comments, issues, code, or contributions
that violate this standard and may temporarily or permanently restrict
participation. Enforcement decisions should be proportional, documented
privately, and applied consistently.

## Reporting

Until a dedicated project address is published, report conduct concerns
privately through the repository owner's GitHub profile. Suspected security
issues should use GitHub's private vulnerability-reporting flow, not a public
issue.
